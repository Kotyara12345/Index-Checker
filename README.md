# 🔍 Index Checker

**Index Checker** — это десктопное приложение с графическим интерфейсом (GUI) на Python/Tkinter для массовой асинхронной проверки индексации URL-адресов в поисковых системах **Yandex** (Search API v2) и **Google** (Custom Search JSON API).

---

## 🌟 Основные возможности

* **Асинхронный движок:** Построен на базе `asyncio` и `aiohttp` для высокопроизводительной сетевой проверки.
* **Настраиваемый Rate Limiter:** Контроль RPS (запросов в секунду) отдельно для Yandex и Google со встроенной защитой от ошибок `429 Too Many Requests`.
* **Поддержка различных форматов ввода:** Загрузка списков URL из файлов `.txt`, `.csv`, `.xlsx`, `.xlsm` с автоматическим распознаванием кодировок (`UTF-8`, `UTF-8-BOM`, `CP1251`) и разделителей.
* **Умная дедупликация:** Автоматическое и ручное удаление дубликатов с учетом нормализации URL (игнорирование регистра, протокола `http/https`, `www` и завершающих слэшей `/`).
* **Экспорт отчётов в Excel:** Форматированная выгрузка результатов в `.xlsx` со стилизованными цветными ячейками (зеленый/красный/желтый), кликабельными гиперссылками, автофильтром и сводной вкладкой «Статистика».
* **Удобный GUI (Tkinter):**
  * Потокобезопасная очередь обновлений UI.
  * Прогресс-бар, счетчики статистики в реальном времени и встроенный журнал (логгер).
  * Корректная остановка проверки (Graceful Stop) без зависания интерфейса.
* **Безопасное хранение ключей:** Возможность считывать API-ключи из переменных окружения или из локального `config.json` (с автоматическим выставлением прав `600` в POSIX-системах).
* **Безопасный XML-паcontent:** Поддержка библиотеки `defusedxml` для защиты от XML-уязвимостей (XXE/BOM).

## 🚀 Установка и запуск

### Требования
* **Python 3.8+**
* Операционная система: Windows, macOS, Linux.

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/index-checker.git
cd index-checker
```

### 2. Установка зависимостей
Установите необходимые библиотеки с помощью `pip`:

```bash
pip install aiohttp openpyxl defusedxml
```

### 3. Запуск приложения

Вы можете запустить приложение через лаунчер:
```bash
python run.py
```

Или как модуль Python:
```bash
python -m index_checker
```

## ⚙️ Настройка API-ключей

Для работы приложения требуются API-ключи поисковых систем. Вы можете задать их в интерфейсе на вкладке **«API ключи»** (они сохранятся в `config.json`) либо через переменные окружения.

### 1. Yandex Search API v2
* **API-ключ**: Получите IAM-токен или API-ключ в Yandex Cloud.
* **Folder ID**: ID каталога в Yandex Cloud.
* **Переменные окружения:**
  * `INDEX_CHECKER_YANDEX_KEY`
  * `INDEX_CHECKER_YANDEX_FOLDER`

### 2. Google Custom Search JSON API
* **API-ключ**: Создайте ключ в Google Cloud Console.
* **CX (ID поискового движка)**: Идентификатор настраиваемой поисковой системы Google (Programmable Search Engine).
* **Переменные окружения:**
  * `INDEX_CHECKER_GOOGLE_KEY`
  * `INDEX_CHECKER_GOOGLE_CX`

> ⚠️ **Обратите внимание:** Бесплатный лимит Google Custom Search составляет **100 запросов в день**. При проверке списка более 100 URL программа выдаст предупреждение.

## 🛠 Руководство по использованию

1. **Ввод URL:**
   * Вставьте список ссылок вручную в текстовое поле на вкладке **«Проверка ссылок»** (каждая ссылка с новой строки).
   * Или нажмите кнопку **«📂 TXT / CSV / XLSX»**, чтобы загрузить ссылки из файла.
2. **Очистка и дедупликация:**
   * При вставке и загрузке программа автоматически находит и отсеивает повторы.
   * Вы также можете вручную отфильтровать дубли кнопкой **«🔁 Удалить дубликаты»**.
3. **Запуск:**
   * Выберите, в каких поисковиках выполнять проверку (отметьте чекбоксы `Yandex` и/или `Google`).
   * Нажмите **«▶ Запустить проверку»**.
   * За ходом проверки можно следить через прогресс-бар, счетчик и журнал в нижней части окна.
4. **Остановка:**
   * В любой момент можно прервать процесс кнопкой **«■ Стоп»**.
5. **Экспорт:**
   * По завершении нажмите **«Экспорт в Excel»**, чтобы сохранить двухстраничный отчёт `.xlsx`.

## 🧪 Разработка и отладка

Для отладки межпоточного взаимодействия Tkinter доступен специальный режим отслеживания вызовов из фоновых потоков:

```bash
export INDEX_CHECKER_DEBUG_THREADS=1
python run.py
```

При включении этого флага любые попытки вызова GUI-методов вне главного потока будут вызывать `RuntimeError`.
